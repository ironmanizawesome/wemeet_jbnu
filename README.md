## 환경 변수 설정(중요)

이 프로젝트는 OpenAI API를 사용합니다. API 키를 코드에 하드코딩하지 않고 환경변수로 주입해야 합니다.

- macOS/Linux(zsh)
	- 터미널에서 다음을 실행하세요:
		- `export OPENAI_API_KEY="<당신의_키>"`
	- 서버 실행 전 동일한 터미널 세션에서 설정되어 있어야 합니다.

- .env 파일 사용을 원한다면, 루트 경로에 `.env` 파일을 만들고 아래와 같이 작성하세요:
	- `OPENAI_API_KEY=<당신의_키>`
	- `.env`는 `.gitignore`에 포함되어 있으므로 Git에 커밋되지 않습니다.

주의: 절대 실제 키를 코드나 Git 커밋에 포함시키지 마세요. 유출 시 즉시 키를 폐기(rotate)하고 새 키를 발급받으세요.

ui는 css 파일을 따로 뺴놓아서 모두 같은 형식으로 편하게 사용하게끔 구상 필요
