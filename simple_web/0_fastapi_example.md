# FastAPI 백엔드 사용 예시 (처음 배우는 분용)

이 문서는 `0_fastapi_example.html` 페이지를 사용해 FastAPI 백엔드와 통신하는 **가장 쉬운 방법**을 설명합니다. HTML과 자바스크립트는 최대한 단순하게 만들었고, 설명은 이 문서에서 합니다.

---

## 1. 준비: 백엔드 실행하기

터미널(명령창)을 열고 아래를 순서대로 실행하세요.

```bash
cd backend_fastapi
uvicorn main:app --reload
```

- 서버가 켜지면 보통 `http://127.0.0.1:8000` 주소에서 동작합니다.
- 브라우저에서 주소를 직접 열어보면 `{ "message": "Hello, FastAPI!" }` 같은 응답을 볼 수 있습니다.

> 참고: 이 저장소의 `backend_fastapi/main.py`에는 CORS 허용이 추가되어 있어, 브라우저에서 다른 출처에서도 호출할 수 있도록 설정되어 있습니다.

---

## 2. 예시 페이지 열기

- 파일: `simple_web/0_fastapi_example.html`
- 이 파일을 더블클릭해서 브라우저로 열어도 되고, VS Code의 Live Server 같은 간단한 웹서버로 열어도 됩니다.

페이지에 보이는 구성은 아주 단순합니다.

- 백엔드 주소 입력칸 (기본값: `http://127.0.0.1:8000`)
- 버튼 2개와 결과 창 2개
  - "GET / 호출" → 서버의 루트(`/`)를 호출합니다.
  - "GET /items/{id}" → `/items/<숫자>`를 호출합니다. 필요하면 `q`에 검색어를 넣으세요.

---

## 3. 어떻게 동작하나요?

- 버튼을 누르면 자바스크립트 `fetch()`로 해당 주소에 요청을 보냅니다.
- 받은 응답(JSON)을 화면의 `pre` 영역에 그대로 보여줍니다.
- HTML과 JS는 최대한 짧게, 필요한 것만 들어 있습니다.

---

## 4. 자주 생기는 문제와 해결

- 파일을 직접 열었을 때(file://) 일부 브라우저 보안 정책 때문에 네트워크 요청이 차단될 수 있습니다.
  - 그럴 땐 VS Code Live Server 같은 간단한 웹서버로 열어보세요.
- 백엔드가 꺼져 있으면 에러가 납니다. 먼저 백엔드를 켜주세요.

---

## 5. 다음 단계 (선택)

- POST/PUT 같은 다른 HTTP 메서드도 버튼을 추가해 실습해보세요.
- 입력값 검증(빈 값, 숫자 아님 등)을 간단히 추가해보세요.
- 실제 프로젝트에서는 CORS를 "모두 허용" 대신, 필요한 출처만 허용하도록 제한하는 것이 좋습니다.
